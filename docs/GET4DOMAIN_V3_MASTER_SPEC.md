# SECTION 4 — DOMAIN SERVICES AND DOMAIN MIGRATION

Domain services are a major Get4Domain product, not merely a website configuration feature.

## 4.1 Domain registration

Initial extensions may include:
- .com
- .in
- .co.in
- .org
- Other extensions supported by the reseller API.

Pricing must be configurable by extension, registration term and reseller cost.

## 4.2 Domain migration and transfer

Create a dedicated Domain Migration Centre.

Support two distinct workflows.

### A. DNS migration without registrar transfer

Vendor already owns a domain and only wants to host the website on Get4Domain.

Workflow:
1. Vendor enters existing domain.
2. Verify domain ownership.
3. Show required DNS changes.
4. Verify DNS configuration.
5. Configure hosting.
6. Provision SSL.
7. Configure canonical domain.
8. Test website.
9. Activate the domain.

This should be the simplest and fastest migration option.

### B. Registrar transfer to Get4Domain reseller

Vendor wants to transfer domain registration management to Get4Domain.

Workflow:
1. Vendor submits domain.
2. Check extension and transfer eligibility.
3. Check domain transfer lock and eligibility restrictions.
4. Explain transfer requirements.
5. Collect the required transfer authorisation code securely.
6. Initiate transfer through the reseller API.
7. Track transfer status.
8. Handle approval and verification requirements.
9. Confirm successful transfer.
10. Update domain management.
11. Set renewal reminders.

Never claim a transfer is complete until the registrar confirms it.

Domain migration must preserve existing website availability wherever practical.

Important:
- Verify ownership.
- Protect transfer authorisation codes.
- Do not expose sensitive domain credentials.
- Preserve DNS records when possible.
- Provide rollback instructions.
- Track expiry and renewal dates.
- Keep domain ownership with the vendor.
