## Decisions taken without asking

1. A design is data inside the category pack's config (`designs[]`: ordered section list with a variant each, theme, style tokens, navigation, footer and action-bar style). The four designs of a family start from one set of family templates, so 24 categories x 4 designs come from shared config, not hand-written pages.
2. New columns on `"VendorCMS"` (additive): `extras` (JSON: headline, sub-line, button label, announcement, trust points, FAQ, steps, stats, team, before/after, and the `sample` markers), `designKey`, `siteStatus` (LIVE default, DRAFT, UNCLAIMED).
3. Starter items are the vendor's own `VendorProduct` rows marked in `customFields` (`sample`, `samplePrice`); the public API removes a sample price and sample customer quotes before they leave the server.
4. Starter pictures are original artwork generated by `scripts/industry-designs/seed-images.js` (no photographs), written to `get4domain_mvp/public/starter/` with the licence in a file.
5. Statistics and team members are never seeded (invented numbers and people would mislead); those sections show only once the vendor adds them.
6. A category can only be created from a flow family plus starter content (the server builds the four designs); an admin may then rename designs, change themes, switch designs on or off (exactly four stay on) and choose the default.
7. Readiness: starter text, starter items and the starter banner do not count as done; the new "Starter text replaced with your own" check is recommended, not required.
8. An empty field on a design page stays empty (no render-time text from the pack): the first headline falls back to the business name, the sub-line to the first line of About.
9. The hidden (DRAFT or UNCLAIMED) site answers with the not-found page and a noindex; the HTTP code stays 200 because the root `loading.tsx` streams every page, exactly as for an unknown address today. Fixing that is a separate change to the root layout.
10. A vendor title is used exactly as written (`title.absolute`); the platform name is no longer appended on vendor sites on the new Website Manager.
11. Test ids added beyond the dispatch: `industry-designs.existing-vendors`.

## Not done / limits

- Starter pictures are original artwork, not photographs: they signal "sample" clearly but are not a substitute for a vendor's own photos. AI Studio pictures were not generated (no credentials in this environment).
- Items are edited in the new Items tab one at a time; bulk import is not built.
- Bulk site creation, the claim flow and promotion are a later dispatch (not built, as instructed).
- The category's items carry sample meta (for example bedrooms and area for properties); these are text only and editable in the Items tab.
- The contact sheet shows starter content in the default theme of each design; the vendor's own colours are changed in Theme and layout.
