# V3 Public Site: Backend and Platform Gaps

Everything the public site needs that the backend or the live app does not give yet, with the shape the front end assumed. Where a route is missing the screen says "not available yet" (or uses the mock layer in review); nothing is faked in real mode.

Owner column: **B** = backend work, **L** = live app (existing files), **O** = owner decision.
