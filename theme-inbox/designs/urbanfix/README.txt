URBANFIX — HOME SERVICES WEBSITE TEMPLATE

Files:
- index.html: Home page
- services.html: Service details and sample pricing page
- styles.css: Responsive styling, layout and CSS-only animations

How to preview:
1. Extract this folder.
2. Open index.html in a modern browser.
3. Use the navigation to open services.html.

Notes:
- Plain HTML and CSS only. No JavaScript and no framework.
- Images and Google Fonts load from external URLs, so an internet connection is needed for those assets.
- Replace UrbanFix branding, phone/email, service areas, prices and sample copy with your business details.
- Prices are illustrative sample rates in INR; confirm actual rates before publishing.
