# Starter pictures

Every picture in this folder is original artwork drawn by `scripts/industry-designs/seed-images.js` from plain shapes (gradients, rings, stripes, dots) and one large outline icon from the Lucide icon set (https://lucide.dev, ISC licence). No photograph and no third-party image is used, so there is nothing to attribute or license from anyone else.

Each picture is processed by the shared upload service's cleaning step (`cleanForWeb`: web format, resized, no camera data) and is stored in the website's own public folder. Vendors replace them with their own photographs in Website Manager; a replaced picture is no longer starter content.
