# Industry designs: Phase 0 audit (15 Oct 2026)

## What we found, in plain sentences

1. **The wrong category is data, not code.** `ksm-webtech-services` is stored with industry `retail` (production read-only audit of 14 Oct, `evidence/website-manager/prod-readonly-raw.json`; it has no site row at all). The signup list (`get4domain_mvp/src/data/industries-list.ts`) does contain **Technology & IT** (`technology`), and the engine has a `technology` builder, so the category exists; the vendor simply was not set to it. There is no pack called "IT and web services" yet, because the website-manager starter packs only knew `technology` as "Technology and IT" with generic text. Cause 1 is confirmed. Fix: set the vendor's category to `technology` (shown as "IT and web services") and give that category its own designs and starter text.
2. **A new site has nothing in it.** The new renderer (`engine/sitedoc/build.ts`) only shows the vendor's own fields. For an empty vendor the only text it can print is the pack's one-line tagline, one sentence of About and the default headline. It has no starter items, no FAQ content on the page (FAQ comes from the pack but is not editable), no trust points, no gallery and no banner (an empty banner is a gradient). The Website Manager dispatch removed render-time stock fallbacks on purpose (correct) and nothing replaced them. Cause 2 is confirmed. Fix: seed starter content into the vendor's own site at creation, marked sample.
3. **Few sections, one layout set for everybody.** The new renderer uses only 8 of the kit's 16 section types and 3 to 4 variants per slot, and the layout choices (`SITE_VARIANTS`) are global, not per category. The older kit builders (`engine/industries/kit/*`) are richer (14 industries, 4 to 9 sections each) but are hand-written per industry and are not used by the new path. Cause 3 is confirmed.
4. **The 14 kit industries are decent but copy other people's images.** The before-screenshots (`before/`) show stock photographs hard-coded in each builder (one hero shows a published book cover). Those pictures are not ours to reuse; the starter images in this dispatch are generated by us.

## Flow families (8)

Shop (cart or order request), Booking and appointment, Enquiry and services, Packages and tours, Menu and orders, Portfolio and gallery, Listings (property), Courses and classes. Every category fits one; no ninth family was needed.

## Existing section types and who uses them (from `before/section-usage.json`)

Used by the 14 kit builders: hero (overlay 7, split 7, panel 1), stats, showcase (cards, menu, tiles, rows), featureIndex, iconGrid, rows, steps, gallery, people, testimonials, faq, enquiry. Real estate and retail are hand-built and use none of these. The new Website Manager renderer uses only hero, showcase, about, gallery, testimonials, faq, enquiry and contact.

Missing for the designs asked for: announcement bar, trust strip, product grid with categories and search, package cards, menu list with veg marks and tabs, pricing table, booking widget variants, before and after, working hours, sticky mobile action bar, footer variants, hero centred and hero with enquiry card.
